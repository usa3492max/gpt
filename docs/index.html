Abridged from a real run against the bundled practice lab: it found an exposed config backup, pulled the database password out of it, recorded the finding, then turned a login-form SQL injection into the flag — eleven steps, no guidance.

Built for unattended runs, not demos

One action per turn

The model reasons, emits one JSON tool call, and the runtime returns the real observation. Nothing is fabricated and every step is reviewable.

Any model, one protocol

Claude, or anything OpenAI-compatible: Ollama, LM Studio, vLLM, OpenRouter, Groq. A tolerant parser absorbs the sloppy JSON weaker models produce.

Survives its own context

A scratchpad plus automatic fact extraction keeps a 60-step run coherent. Compaction is deterministic and spends no API calls.

Live feed you can read

Thinking panels, a per-action spinner and a flag banner in the terminal — plus plain text for logs and a JSON stream for your own tooling.

Guardrails that fire

Scope is enforced on every host, URL and Python snippet; destructive commands are blocked. Refusals go back to the model so it adapts instead of retrying.

A report, not a log

Every run leaves report.md, results.json, the full transcript, the replayable feed and raw loot in one directory.

How it works

  1. Brief — target, scope, objective and any hints you give it.
  2. Reason — the model reads the last observation and picks one hypothesis.
  3. Act — exactly one tool call, checked against scope and a blast-radius blocklist.
  4. Observe — real output comes back, facts and flags are scraped into the scratchpad.
  5. Adapt — repeats are suppressed, unproductive streaks trigger a change of tactic.

The state block is rebuilt for every call, so the model always sees current facts rather than a stale copy of its own history — which is what keeps a sixty-step run coherent. Read the architecture →

Guardrails, stated plainly

  • Authorisation gate. A non-loopback target requires --i-am-authorized.
  • Scope enforcement. Every hop, URL and Python snippet is checked. Private ranges are allowed because CTF boxes pivot; arbitrary public hosts are refused with the exact --scope you would need.
  • Blast radius. mkfs, dd of=/dev/sd*, rm -rf /, fork bombs and shutdown are blocked outright.
  • Hard limits. Per-command timeouts, a 2 MB output cap, step, time and cost budgets, and a stop after eight unproductive actions.
  • Full audit trail. Every action, refusal and observation is written to the run directory.

This is not a sandbox for untrusted code — the container is the boundary — and it is not a substitute for a human tester's judgement. Findings are the agent's observations; verify them before disclosure.
